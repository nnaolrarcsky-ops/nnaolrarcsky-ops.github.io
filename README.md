# ポートフォリオ公開サイト

HTML、CSS、JavaScriptを用いて製作するポートフォリオ公開サイトです。
Webサイトの制作に加え、Git・GitHubによるバージョン管理や、GitHub Flowを用いた開発手法の習得を目的としています。

## 公開サイト

**URL:**[https://nnaolrarcsky-ops.github.io/](https://nnaolrarcsky-ops.github.io/)

GitHub Pagesを利用して公開しています。

## 使用技術・開発環境
- フロントエンド...HTML5、CSS3、JavaScript
- 開発環境...Eclipse IDE
- バージョン管理...Git/GitHub
- 開発フロー...GutHub Flow
- ホスティング...GitHub Pages

## 開発・バージョン管理
開発にはGitHub Flowを採用しています

バージョン番号は[Semantic Versioning](http://semver.org/lang/ja/)を参考に管理し、
リリース時には、GitタグとGitHub Releaseを利用しています。

## 変更履歴・リリース情報
各バージョンの変更履歴は、Keep a Changelogを参考に'CHANGELOG.MD'で管理しています。

- **[CHANGELOG.md](CHANGELOG.md)**—バージョンごとの変更内容
- **[GitHub Release](https://github.com/nnaolrarcsky-ops/nnaolrarcsky-ops.github.io/releases/)**
— リリースノート・Gitタグ・ソースコード
